Este projeto consiste em um bot de atendimento automático para WhatsApp, desenvolvido utilizando Node.js.

## 📚 **Contexto do Projeto:**  
> Este bot foi desenvolvido como parte de estudos pessoais em Node.js, automação e integração com APIs do WhatsApp. Não está em produção nem afiliado a nenhuma empresa real.

## 🚀 Funcionalidades

- Conexão via QR Code para autenticação no WhatsApp
- Respostas automáticas baseadas em mensagens pré-programadas
- Fluxo de atendimento simples e direto
- Reinício automático da conversa após encerramento

## ⚙️ Como funciona

Ao iniciar a aplicação, é gerado um QR Code no terminal.  
Após escanear o código com o WhatsApp, o bot é conectado à conta e passa a responder automaticamente as mensagens recebidas.

O sistema utiliza um conjunto de perguntas e respostas previamente definidas para simular um atendimento automatizado.
